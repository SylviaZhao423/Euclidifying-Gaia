## Notes & Ideas (edit freely)

### Mission context to include (Slide 2-3):

- Gaia: L2 orbit, whole-sky survey, 1.8B sources, final shutdown Mar 27 2025
- Euclid: L2 orbit, launched Jul 2023, deep-field survey, ~6yr mission
- Key contrast: Gaia = whole sky but limited morphology; Euclid = deep fields with excellent morphology but slow (few fields so far)
- Euclid VIS saturation limit → biased toward faint sources → more galaxies
- The ML bridge: use Euclid labels to classify Gaia's whole sky
